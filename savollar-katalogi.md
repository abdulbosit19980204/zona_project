# Keladigan savollar katalogi (xodimlar va turlar bo'yicha)

---

## 1. Saidabror — L1, ma'lumotlar operatori

### 1.1. Klient kartochkasi
- Yangi klient qo'shib bering (nomi, STIR, manzil, telefon, kontakt)
- Klientning STIR raqami noto'g'ri, o'zgartiring
- Klient nomi noto'g'ri yozilgan
- Klient manzili o'zgardi
- Klient telefon raqamini yangilang
- Kontakt shaxsni (egasi, sotuvchi) o'zgartiring
- Klient lokatsiyasi xaritada noto'g'ri turibdi
- Klientni boshqa agentga o'tkazing
- Klientni boshqa marshrutga yoki haftaning boshqa kuniga qo'ying
- Klient kanali yoki kategoriyasi noto'g'ri (do'kon, supermarket, HoReCa va h.k.)
- Klientning narx turini o'zgartiring
- Klient yopildi, nofaol qilib qo'ying
- Nofaol klientni qayta faollashtiring
- Klientni boshqa filialga o'tkazing
- Klient kartochkasiga hujjat yoki rasm biriktiring

### 1.2. Hujjatlar (zakaz, vozvrat, to'lov)
- Zakazni noto'g'ri kiritdim, tahrirlang
- Zakazni o'chirib bering
- Zakaz ikki marta tushib qoldi
- Zakaz boshqa klientga yozilib ketdi
- Zakazdagi tovar soni noto'g'ri
- Zakazdagi narx noto'g'ri
- Zakazga tovar qo'shing yoki olib tashlang
- Vozvrat (qaytarish) hujjatini kiriting
- Vozvrat noto'g'ri kiritilgan, tuzating
- Hujjat sanasini o'zgartiring
- To'lov boshqa klientga tushib qolgan
- To'lov ikki marta tushgan
- To'lov summasi noto'g'ri kiritilgan
- Hujjatni o'tkazilmagan holatga qaytaring
- Hujjatni boshqa agent nomiga o'tkazing

### 1.3. Aksiyani klientga biriktirish
- Shu klientni aksiyaga qo'shing
- Klientlar ro'yxatini (Excel) aksiyaga biriktiring
- Klient aksiyada yo'q, agentda ko'rinmayapti (biriktirilmagan bo'lsa)
- Klientni aksiyadan chiqaring
- Aksiya qaysi klientlarga biriktirilganini ro'yxat qilib bering
- Klientni boshqa aksiyaga o'tkazing
- Aksiya muddati tugagan klientlarni tozalang

### 1.4. Dublikatlar
- Bitta klient ikki marta ochilgan, birlashtiring
- Bitta STIR bilan ikkita kartochka bor
- Bitta telefon raqam bilan bir nechta klient bor
- Tovar (nomenklatura) dublikat bo'lib qolgan
- Dublikat klientdagi zakaz va qarzni asosiy kartochkaga o'tkazing
- Dublikatlar ro'yxatini chiqarib bering

### 1.5. Ma'lumot chiqarib berish (vygruzka)
- Agent bo'yicha klientlar ro'yxati kerak
- Filial bo'yicha klientlar ro'yxati kerak
- Shu oydagi savdoni Excelga chiqarib bering
- Zakazlar ro'yxati kerak (davr, agent, klient bo'yicha)
- Debitorlik (qarzdorlik) ro'yxati kerak
- Klient bilan akt sverka kerak
- Aksiya bo'yicha qancha sotilganini chiqarib bering
- Nofaol (zakaz bermayotgan) klientlar ro'yxati
- Vozvratlar ro'yxati kerak
- Yangi ochilgan klientlar ro'yxati (davr bo'yicha)
- Lokatsiyasi yo'q klientlar ro'yxati
- STIR raqami yo'q klientlar ro'yxati

### 1.6. Nomenklatura (tovar)
- Yangi tovar (SKU) qo'shing
- Tovar nomini o'zgartiring
- Shtrix-kodini qo'shing yoki o'zgartiring
- O'lchov birligi noto'g'ri (dona, blok, karobka)
- Karobkadagi dona sonini tuzating
- Tovarni nofaol qiling
- Tovarni guruhga yoki brendga biriktiring
- Tovarga narx turi biriktiring

## 2. Xusniddin — L1, IT operator

### 2.1. Dostup ochish
- Yangi xodim keldi, 1C ga dostup oching
- PRBC ga dostup oching
- Telegram botga dostup oching
- Korporativ pochta oching
- Agentga mobil ilovaga login bering
- Menga yangi filial yoki omborga huquq qo'shing
- Hisobotni ko'rishga huquq bering
- Rolimni o'zgartiring (masalan, agent → supervayzer)
- RDP orqali kirish kerak
- VPN kerak
- Umumiy papkaga (tarmoq diskiga) dostup bering
- Vaqtincha dostup bering (o'rinbosar uchun)

### 2.2. Dostup yopish
- Xodim ishdan ketdi, barcha dostuplarni yoping
- Ta'tilga chiqdi, vaqtincha bloklang
- Agent telefonini yo'qotdi, akkauntni bloklang
- Agentlar almashdi, eski loginni yoping
- Ortiqcha huquqlarni olib tashlang
- Xodim boshqa bo'limga o'tdi, eski huquqlarni yoping

### 2.3. Parol
- Parolni unutdim
- Akkaunt bloklanib qoldi
- Parol muddati tugadi
- Parolni almashtirib bering
- Telegram botga qayta ulanish kerak
- Botni boshqa telefon raqamiga bog'lash kerak
- SMS yoki 2FA kod kelmayapti
- Pochta paroli ishlamayapti

### 2.4. Uzilishlarni kuzatish va xabar berish
- 1C ochilmayapti
- 1C juda sekin ishlayapti
- Bot javob bermayapti
- PRBC ochilmayapti
- Agentda sinxronizatsiya bo'lmayapti, zakazlar ketmayapti
- Hammada ishlamayaptimi yoki faqat mendami? (birinchi qadam: muammo qanchalik keng ekanini aniqlash)
- Qachon tuzaladi? (holat haqida xabar berish)
- Pochta kelmayapti yoki ketmayapti
- Muammo kimga yetkazildi, holati qanday?
- Uzilish tugadi, hammaga xabar berish

### 2.5. Ilova va versiya
- Mobil ilovani o'rnatib bering
- Ilovani yangi versiyaga yangilang
- Ilova "login xato" deyapti
- Ilova eski versiya deb kirgizmayapti
- Yangi telefonga ilovani ko'chirish kerak
- 1C klientni (ярлык / baza) qo'shib bering

## 3. Abdulbosit — Nazorat, DevOps

### 3.1. Serverlar
- 1C server ishlamayapti (hamma uchun)
- Server juda sekin, hamma qotib qoldi
- Disk to'lib qoldi
- Backup olinmadi yoki backup tekshiruvi
- Bazani backupdan tiklash kerak
- 1C litsenziyasi tugadi yoki yetmayapti
- SQL server muammosi
- Bot serveri ishlamayapti
- PRBC serveri ishlamayapti
- Server qayta yuklandi, xizmatlar ko'tarilmadi
- Yangi server yoki virtual mashina kerak
- Test baza kerak (dasturchilar uchun)

### 3.2. Aloqa kanallari
- Filial bilan aloqa yo'q (VPN uzildi)
- Provayder internetni uzdi
- Asosiy kanal ishlamayapti, zaxira kanalga o'tkazish
- Router yoki Mikrotik muammosi
- Tashqi IP yoki port ochish kerak (integratsiya uchun)
- Domen yoki SSL sertifikat muddati tugadi
- Pochta serveri muammosi
- Yangi filialni tarmoqqa ulash

### 3.3. Xavfsizlik
- Shubhali kirishlar bor
- Virus yoki shifrlovchi (ransomware) gumoni
- Parol siyosatini o'zgartirish
- Kimdir ruxsatsiz ma'lumot chiqargan bo'lishi mumkin
- Ishdan ketgan xodim dostupi to'liq yopilganini tekshirish

### 3.4. Nazorat va eskalatsiya
- Xusniddin yoki Jahongir hal qila olmadi
- Murojaat muddati (SLA) o'tib ketdi
- Bir xil muammo takrorlanyapti
- Ish ko'p, yordam kerak
- Murojaatlar statistikasi yoki hisoboti kerak
- L1 xodimlar o'rtasida ishni taqsimlash
- Muhim uzilish bo'yicha rahbariyatga hisobot

---

## 4. Jahongir — L1, IT texnik yordam

### 4.1. Kompyuter
- Kompyuter yoqilmayapti
- Kompyuter juda sekin
- Windows ochilmayapti yoki xato beryapti
- Dastur o'rnatib bering (Office, 1C klient, brauzer, arxivator)
- Virus bor shekilli
- Kompyuterda ovoz yoki mikrofon ishlamayapti
- Kompyuter o'zi o'chib qolyapti
- Yangi kompyuterni sozlab bering
- Fayllarni eski kompyuterdan yangisiga ko'chiring

### 4.2. Printer va skaner
- Printer chop etmayapti
- Kartrij tugadi, almashtiring
- Printer drayverini o'rnating
- Printerni tarmoqqa ulang
- Qog'oz tiqilib qoldi
- Skaner ishlamayapti
- Yorliq (termo) printer ishlamayapti
- Chek printer ishlamayapti

### 4.3. Tarmoq
- Bir xonada internet yo'q
- Wi-Fi ishlamayapti yoki signal past
- Yangi kabel tortish kerak
- Tarmoq rozetkasi ishlamayapti
- Switch yoki router o'chib qolgan
- Yangi ish joyiga tarmoq olib borish

### 4.4. Qurilmalar
- Monitor ishlamayapti
- Klaviatura yoki sichqoncha buzildi
- UPS (uzluksiz quvvat manbai) ishlamayapti
- IP telefon ishlamayapti
- Kamera (CCTV) ko'rsatmayapti
- Proyektor yoki televizorni ulang
- Planshet yoki TSD skaner ishlamayapti
- Qurilmani ta'mirga topshirish

### 4.5. Ish joyi
- Yangi xodim uchun ish joyi tayyorlang
- Xodim boshqa xonaga ko'chdi
- Ishdan ketgan xodimdan qurilmalarni qaytarib oling
- Qurilmalar ro'yxati (inventarizatsiya) kerak
- Majlis xonasini tayyorlang (proyektor, ovoz, internet)

## 5. Pro-target — Tashqi hamkor

### 5.1. Klient tasdiqlash
- Yangi klient qachon tasdiqlanadi?
- Klient nega rad etildi?
- Klient hujjatlari yetishmayapti
- Klient ma'lumotlari ProTargetda noto'g'ri
- Tasdiqlangan klient ro'yxati kerak

### 5.2. Aksiyalar
- Aksiya shartlari qanday?
- Qaysi klientlar aksiyada qatnashadi?
- Bonus yoki sovg'a qachon beriladi?
- Aksiya ProTarget tomonda ishlamadi
- Aksiya natijalari (ProTarget hisobi bo'yicha)

### 5.3. ProTarget dasturi muammolari
- ProTarget ilovasi ochilmayapti
- ProTarget ilovasida ma'lumot ko'rinmayapti
- ProTarget login yoki paroli

### 5.4. Pro-targetga YUBORILMAYDI (yo'naltirish kerak)
- 1C bo'yicha har qanday savol → Saidabror yoki Xusniddin
- PRBC bo'yicha savol → Xusniddin
- Bot bo'yicha savol → Xusniddin (uzilish) yoki Dasturchilar (xato)

---

## 6. Dasturchilar — L3

### 6.1. Yangi aksiya
- Yangi aksiya mexanikasini tizimga sozlash
- Aksiya shartini o'zgartirish (foiz, chegara, muddat)
- Aksiya biriktirilgan, lekin hisoblanmayapti
- Aksiya bo'yicha bonus noto'g'ri hisoblandi

### 6.2. Integratsiya
- 1C ↔ ProTarget ma'lumot almashinuvi to'xtadi
- 1C ↔ bot almashinuvi ishlamayapti
- 1C ↔ PRBC integratsiyasi xatosi
- EDO yoki soliq (elektron faktura) integratsiyasi xatosi
- Bank bilan almashinuv xatosi
- Yangi tizim bilan integratsiya qilish so'rovi

### 6.3. Bot xatolari
- Bot noto'g'ri ma'lumot ko'rsatyapti
- Bot buyruqqa xato javob beryapti
- Botga yangi funksiya qo'shish
- Bot xabarnomasi (bildirishnoma) kelmayapti

### 6.4. Hisobot xatolari
- Hisobotda summa noto'g'ri chiqyapti (ma'lumot to'g'ri bo'lsa)
- Hisobot ochilmayapti yoki xato beryapti
- Hisobotga yangi ustun yoki filtr qo'shish
- Yangi hisobot yaratish
- Hisobot juda sekin shakllanyapti

### 6.5. Dastur xatolari
- 1C da xato oynasi chiqyapti (barcha uchun)
- Mobil ilova yopilib qolyapti (crash)
- PRBC funksiyasi noto'g'ri ishlayapti
- Yangi funksiya yoki o'zgartirish so'rovi

---

## 7. Supervayzerlar — Biznes

### 7.1. Agentning birinchi murojaat nuqtasi
- Zakaz o'tmayapti (birlamchi tekshiruv, keyin yo'naltirish)
- Klient ko'rinmayapti
- Aksiya ko'rinmayapti
- Narx noto'g'ri chiqyapti
- Ilova ishlamayapti
- Qaysi xodimga murojaat qilish kerak?

### 7.2. Tasdiqlash so'rovlari
- Yangi klient ochishni tasdiqlash
- Klientni boshqa agentga o'tkazishni tasdiqlash
- Klientni aksiyaga qo'shishni tasdiqlash
- Vozvratni tasdiqlash
- Chegirma yoki maxsus narxni tasdiqlash
- Zakazni o'chirish yoki tahrirlashni tasdiqlash
- Marshrutni o'zgartirishni tasdiqlash
- Yangi agentga dostup ochishni tasdiqlash
- Agent dostupini yopishni tasdiqlash
- Kredit limiti yoki to'lov muddatini tasdiqlash

### 7.3. Biznes savollari
- Plan va bajarilish holati
- Aksiya qoidalari agentlarga tushuntirish
- KPI va bonus hisob-kitobi
- Klient bilan nizoli holatlar

## 8. Chegaraviy holatlar (kimga yuborish kerak)

- **"Aksiya ko'rinmayapti"**
  - Klient aksiyaga biriktirilmagan → Saidabror
  - Biriktirilgan, lekin ishlamayapti → Dasturchilar
  - ProTarget tomonda → Pro-target

- **"1C ochilmayapti"**
  - Bitta xodimda, login/parol → Xusniddin
  - Bitta xodimda, kompyuter muammosi → Jahongir
  - Hammada → Xusniddin xabar beradi → Abdulbosit

- **"Hisobotda summa noto'g'ri"**
  - Ma'lumot noto'g'ri kiritilgan → Saidabror
  - Ma'lumot to'g'ri, hisob-kitob xato → Dasturchilar

- **"Bot javob bermayapti"**
  - Uzilish holatini tekshirish → Xusniddin
  - Server ishlamayapti → Abdulbosit
  - Bot ishlayapti, lekin noto'g'ri javob beradi → Dasturchilar

- **"Agentda zakaz ketmayapti"**
  - Login/dostup → Xusniddin
  - Klient yoki tovar ma'lumoti xato → Saidabror
  - Ilova crash yoki sinxronizatsiya xatosi → Dasturchilar
  - Server yoki aloqa → Abdulbosit

- **"Internet yo'q"**
  - Bitta xona yoki kompyuter → Jahongir
  - Butun ofis yoki filial → Abdulbosit

- **"Yangi xodim keldi"**
  - Ish joyi va qurilma → Jahongir
  - Dasturlarga dostup → Xusniddin (supervayzer yoki rahbar tasdiqlagandan keyin)
