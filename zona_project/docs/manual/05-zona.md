# Mas'uliyat platformasi (Zona)

> Kompaniya tuzilmasi va kim nimaga javobgarligi: bo'limlar, xodimlar, jarayonlar, matritsa, tasdiqlash, tahlil va
> "kimga murojaat qilish kerak" qidiruvi.

Bu modul Support bot va PRBC uchun **mas'ullar manbai**: bilim bazasidagi mas'ul, toifa mas'uli, guruh ijrochisi —
hammasi shu yerdagi xodim va jamoalardan olinadi.

## Asosiy bo'limlar

| Bo'lim | Nima uchun |
|---|---|
| **Bosh sahifa** | Umumiy ko'rinish va ogohlantirishlar |
| **Tashkilot** | Bo'lim → jamoa → xodim tuzilmasi (xarita) |
| **Mas'uliyat xaritasi** | Xodim yoki jarayon tanlab, uning barcha aloqalarini ko'rish |
| **Bo'limlar, Xodimlar** | Ro'yxatlar; xodim kartasi (360°): vazifalari, vakolatlari, jarayonlari |
| **Kontaktlar** | Kompaniya kontaktlari (hudud kodi, Telegram) — PRBC bo'shaganlarni shu yerda belgilaydi |
| **Kim javob beradi** | Savol yozing — kimga murojaat qilish kerakligini topadi (lotin/kirill/rus, imlo xatolari) |
| **Shpargalka** | Tez-tez kerak bo'ladigan ma'lumotlar |
| **Mas'uliyatlar, Jarayonlar, Matritsa** | Har jarayonda kim egasi, bajaradi, tasdiqlaydi, nazorat qiladi, yordam beradi, zaxira |
| **Tasdiqlash** | O'zgarish takliflari (taklif → tasdiq) |
| **Tahlil, Yuklama, Bo'shliqlar, Hisobotlar** | Egasiz jarayonlar, mas'ulsiz vazifalar, kesishgan mas'uliyat, yuklama |
| **AI tahlillar, Audit** | AI so'rovlari tarixi va barcha o'zgarishlar jurnali |
| **Sozlamalar** | Foydalanuvchilar, rollar, AI provayderlar, til |

## Xodim va jamoa (mas'ul sifatida)

- **Xodim** (masalan, Saidabror, Xusniddin) — Telegram username'i bilan; PRBC'dagi shaxsga bog'lanadi.
- **Jamoa** (masalan, Pro-target, Supervayzerlar, IT support) — a'zolari (kontaktlar) bilan. Jamoa mas'ul bo'lsa,
  javobda a'zolar belgilanadi; vazifa ijrochisi a'zolardan PRBC'da topilgani.
- **Jamoa a'zosi (yakka xodim).** O'z kartochkasi bor xodim jamoa ishini ham bajarsa (masalan, Kamoliddin va Timur —
  «Dasturchilar jamoasi», Ulug'bek va Alisher bilan birga), xodim oynasida **«Jamoa a'zosi»** maydonida jamoani
  tanlang. Shunda: jamoa mas'ul bo'lgan savolda u ham belgilanadi; Support → Sozlamalarda jamoa ro'yxatida chiqadi;
  xodimlar hisobotida «Jamoa» ustunida jamoa nomi; **haftalik yuklamada** jamoa yuklamasidan teng ulush oladi
  (jamoa yuklamasi ÷ kontaktlar va a'zolar soni). Jamoaning o'z qatori o'zgarmaydi.
- **Asosiy operator (umumiy akkaunt).** Bir nechta odam ishlatadigan Telegram akkaunti (masalan @IT_StarGroup —
  «IT support (umumiy akkaunt)» jamoasida) uchun jamoa a'zolari ro'yxatida **«Asosiy operator»** tanlanadi
  (masalan, Xusniddin). Shunda bu akkauntdan yozilgan javoblar xodimlar hisobotida operator qatoriga qo'shiladi
  («@IT_StarGroup orqali» belgisi bilan), PRBC vazifasi ijrochisi ham operator bo'ladi. Operator tanlanmasa —
  umumiy akkaunt avvalgidek ijrochi hisoblanmaydi.
- Bo'limlar: IT xizmati, Dasturlash, Savdo, Savdo operatsiyalari.
